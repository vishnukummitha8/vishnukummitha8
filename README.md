# JSW Motors MES Login Page

A high-fidelity Manufacturing Execution System (MES) login page for **JSW Motors**, built with React, TypeScript, and Vite.

## Features

- Full-screen automotive manufacturing background with dark blue gradient overlay
- JSW Motors branding with headline, taglines, and four feature info cards
- Login card with username, password, and plant selection fields
- Password visibility toggle, remember me, and forgot password link
- Footer bar with secure access, real-time data, and connected operations highlights
- Responsive layout for desktop, tablet, and mobile

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```
