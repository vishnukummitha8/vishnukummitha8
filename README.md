# JSW Motors MES Login

Manufacturing Execution System login page for JSW Motors.

## Preview

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Structure

```
index.html
css/styles.css
js/main.js
assets/
  factory-bg.jpg
  jsw-logo.png
  login-card-art.png
```

## Features

- Full-bleed factory hero background
- JSW Motors branding and login card
- Username / password / plant selection
- Password visibility toggle
- Feature tiles and footer strip matching the MES design
