# HTML & CSS Basic Notes

Study notes for learning HTML and CSS fundamentals, packaged as a Word document.

## File

- **[HTML_CSS_Basic_Notes.docx](./HTML_CSS_Basic_Notes.docx)** — download and open in Microsoft Word, Google Docs, or LibreOffice.

## What's Inside

1. Introduction to HTML & CSS  
2. HTML Basics (structure, tags, attributes, lists, tables, forms, semantic HTML)  
3. CSS Basics (selectors, box model, flexbox, grid, positioning, responsive design)  
4. Best practices for beginners  
5. Quick reference cheatsheet  
6. Mini practice project idea  
7. Glossary  

## Regenerate

```bash
pip install python-docx
python3 create_notes.py
```
