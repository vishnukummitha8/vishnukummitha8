# JSW Motors – MES Login

Pixel-faithful Manufacturing Execution System (MES) login page for JSW Motors.

## Preview

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 5173
```

Then visit `http://localhost:5173`.

## Structure

- `index.html` – page markup
- `css/styles.css` – layout and brand styling
- `js/main.js` – password visibility + login form handling
- `assets/` – factory background, JSW logo, and car line art
